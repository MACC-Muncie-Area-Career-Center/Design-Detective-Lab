Color Vocabulary

The term behind each answer is highlighted. Adobe Color's name for a rule is shown in blue where it differs.

Relationships are taught on the traditional RYB (red, yellow, blue) painter's wheel. Screen tools that use an RGB wheel place some complements differently: on an RGB wheel, blue's complement is yellow rather than orange. Color-blindness views use the Machado (2009) simulation and are approximations. Names and places in the examples are fictional.
